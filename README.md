# Menaka Jewellers — Mobile-First Catalog Website

A mobile-first React + Vite showcase catalog for **Menaka Jewellers**, celebrating South Indian temple jewellery, bespoke craftsmanship, and verified hallmarked gold.

---

## 🏛️ Brand Overview & Verified Credentials
- **Heritage**: Crafting elegance since 1979
- **Assurance**: 100% BIS Hallmark Gold
- **Custom Atelier**: Custom designs ready in 7 days
- **Logistics**: Ships across India & USA
- **Location**: Based in Warangal, Telangana, India
- **Reference**: Official Instagram [@menakajewellers__](https://www.instagram.com/menakajewellers__/)

---

## 📱 Features & Highlights
- **Mobile-First Luxury Experience**: Designed specifically for smartphone screens with seamless desktop scalability.
- **Temple Jewellery Aesthetic**: Deep burgundy/maroon, antique gold, and warm ivory palette.
- **6 Category Showcase**: Gold, Diamond, Bridal, Vaddanam, Earrings, Bangles.
- **Direct WhatsApp Concierge**: Instant one-tap enquiry with pre-filled message including product name and SKU.
- **Honest Catalog Policy**: Strictly adheres to verified claims with 8 curated demo pieces clearly marked. Zero invented prices, weights, or awards.
- **Next.js Ready**: Lightweight, modular TypeScript architecture with zero vendor lock-in.

---

## 🛠️ Tech Stack
- **Build Tool**: Vite
- **UI Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS + Custom Design Tokens
- **Icons**: Lucide React
- **Routing**: React Router DOM (v6)

---

## 🚀 Quickstart & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Production Build & Preview
```bash
npm run build
npm run preview
```
